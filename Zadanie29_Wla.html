1. W jaki sposób można określić właściwość danego obiektu (dwa sposoby wraz z przykładami)?


Odpowiedź:
Właściwość obiektu w JavaScript można określić na dwa sposoby:

1) Notacja kropkowa:
let osoba = {};
osoba.imie = "Jan";

2) Notacja tablicowa:
let osoba2 = {};
osoba2["nazwisko"] = "Kowalski";

2. W jaki sposób można odwołać się do pól (właściwości) i metod?


Odpowiedź:
Do pól i metod obiektu można odwołać się za pomocą notacji kropkowej oraz tablicowej:

console.log(osoba.imie);
osoba.przedstawSie();

console.log(osoba["imie"]);
osoba["przedstawSie"]();

3. Wymień cechy charakterystyczne konstruktora.


Odpowiedź:
Konstruktor:
- jest wywoływany automatycznie podczas tworzenia obiektu
- służy do inicjalizacji pól obiektu
- ma tę samą nazwę co klasa lub funkcja konstruktora
- jest wywoływany przy użyciu słowa kluczowego new

4. Konstruowanie obiektu na podstawie przykładu – obiekt ma trzy pola oraz jedną metodę.


let samochod = {
marka: "Toyota",
rok: 2020,
kolor: "czerwony",
jedz: function() {
console.log("Samochód jedzie");
}
};

5. Znaczenie słowa this. Jak oddzielamy pola oraz metody?


Odpowiedź:
Słowo kluczowe this odnosi się do bieżącego obiektu, w którym zostało użyte.
Pola i metody oddzielamy za pomocą kropki.

let osoba3 = {
imie: "Anna",
przywitaj: function() {
console.log("Cześć, jestem " + this.imie);
}
};

6. Konstruktor w JavaScript na podstawie przykładu wraz z opisem.


Odpowiedź:
Konstruktor to funkcja służąca do tworzenia obiektów oraz inicjalizacji ich pól.

function Osoba(imie, wiek) {
this.imie = imie;
this.wiek = wiek;
}

7. Znaczenie słowa kluczowego new wraz z przykładem.


Odpowiedź:
Słowo kluczowe new służy do tworzenia nowego obiektu na podstawie konstruktora.

let osoba4 = new Osoba("Jan", 30);

8. Znaczenie słowa kluczowego prototype wraz z przykładem i opisem.


Odpowiedź:
Prototype umożliwia dodawanie metod i właściwości do wszystkich obiektów utworzonych przez dany konstruktor.
Dzięki prototype metody są współdzielone, co pozwala oszczędzać pamięć.

Osoba.prototype.przedstawSie = function() {
console.log("Mam na imię " + this.imie);
};
