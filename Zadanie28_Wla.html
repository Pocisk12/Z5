2. Programowanie strukturalne – opis i założenia


Programowanie strukturalne to paradygmat programowania opierający się
na podziale kodu źródłowego na procedury oraz hierarchicznie ułożone bloki.
Wykorzystuje struktury kontrolne takie jak instrukcje wyboru i pętle.
Zwiększa czytelność kodu i ułatwia analizę programów.
Stanowi alternatywę dla tzw. „spaghetti code” wynikającego z użycia goto.

Założenia programowania strukturalnego:
1. Każdy blok kodu ma jeden punkt wejścia (może mieć wiele punktów wyjścia)
2. Instrukcje wykonywane są w określonej kolejności
3. Stosowanie instrukcji warunkowych (if, if else)
4. Stosowanie pętli (for, while, do while)
5. Unikanie instrukcji skoku (goto)
6. Unikanie instrukcji break i continue
7. Funkcje i zmienne nie są ze sobą bezpośrednio powiązane


Przykład programowania strukturalnego

let liczba1 = 10;
let liczba2 = 5;

if (liczba1 > liczba2) {
console.log("Liczba1 jest większa");
}

for (let i = 0; i < 3; i++) {
console.log(i);
}

3. Programowanie obiektowe – definicja


Programowanie obiektowe (ang. Object-Oriented Programming – OOP)
to sposób programowania, w którym program jest zbiorem obiektów.

Obiekt:
- posiada stan (pola, dane)
- posiada zachowanie (metody)

Obiekty są tworzone na podstawie wcześniej zdefiniowanych klas
i komunikują się ze sobą w celu realizacji zadań programu.


Przykład programowania obiektowego


class Okno {
constructor(szerokosc, wysokosc) {
this.szerokosc = szerokosc;
this.wysokosc = wysokosc;
}

zmienRozmiar(nowaSzerokosc, nowaWysokosc) {
this.szerokosc = nowaSzerokosc;
this.wysokosc = nowaWysokosc;
}
}

4. Dlaczego stosujemy programowanie obiektowe?

1. Jest bardziej naturalne i zgodne z rzeczywistością
2. Pozwala odwzorować świat rzeczywisty w postaci obiektów
3. Umożliwia lepsze zarządzanie pamięcią – obiekty można usuwać
4. Ułatwia ponowne użycie kodu dzięki klasom
5. Dobrze zaprojektowane klasy mogą być używane przez innych programistów

5. Podstawowe pojęcia programowania obiektowego

Klasa – opis (definicja) obiektu, zawiera pola i metody
Obiekt – instancja klasy, byt utworzony na jej podstawie
Właściwość – cecha obiektu (pole), np. kolor
Metoda – czynność wykonywana przez obiekt
Konstruktor – metoda wywoływana podczas tworzenia obiektu
Dziedziczenie – przejmowanie cech innej klasy
Hermetyzacja – ukrywanie wnętrza klasy przed światem zewnętrznym
Polimorfizm – możliwość różnego zachowania obiektu w zależności od kontekstu
